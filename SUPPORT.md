# Support

DevToolkit is an open-source community project. Support is best-effort and does not come with an SLA.

## Where to ask

Use GitHub Issues when you have:

- a reproducible bug
- a feature request
- a proposal for a new developer tool
- a documentation problem

Before opening an issue, search existing issues and read the README/CONTRIBUTING guide.

## Include useful details

For bugs, provide:

- operating system
- Node.js version
- DevToolkit commit/version
- tool being used
- exact steps to reproduce
- expected behavior
- actual behavior
- relevant logs with secrets/private paths removed
- sample files only when they are safe to publish

## Security issues

Do not use normal support issues for exploitable security vulnerabilities. Follow `SECURITY.md` and report them privately.

## Hosted instances

The repository provides self-hostable software. The project owner is not responsible for third-party DevToolkit instances, their uptime, privacy practices, or file retention behavior.

If you operate your own instance, follow `DEPLOYMENT.md` and `SECURITY.md`.
