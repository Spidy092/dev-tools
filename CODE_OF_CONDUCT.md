# Code of Conduct

DevToolkit is an open-source project for developers of different backgrounds and experience levels. We want participation to be useful, respectful, and welcoming.

## Expected behavior

Participants should:

- discuss ideas and code respectfully
- critique the work, not the person
- assume good intent while still being clear about technical problems
- welcome questions from newer contributors
- give actionable review feedback
- respect privacy and security concerns
- avoid harassment, discrimination, threats, personal attacks, or deliberately disruptive behavior

## Unacceptable behavior

The following are not acceptable in project spaces:

- harassment or targeted intimidation
- discriminatory or demeaning comments
- sexualized or violent content directed at participants
- publishing another person's private information without permission
- repeated spam, trolling, or intentionally derailing technical discussions
- pressuring maintainers or contributors for immediate responses
- knowingly submitting malicious code, exploit payloads, or unsafe changes without appropriate private security coordination

## Technical disagreement

Strong technical disagreement is normal. Keep discussions specific:

- explain the risk or tradeoff
- provide evidence or a reproduction where possible
- propose alternatives
- accept maintainers' final project-scope decisions even when you would choose differently

## Enforcement

Project maintainers may edit or remove comments, close discussions, reject contributions, temporarily restrict participation, or permanently ban participants when behavior harms the project or community.

For serious conduct concerns, contact the repository owner privately rather than escalating the situation publicly.

## Scope

This code applies to GitHub issues, pull requests, discussions, reviews, project documentation, and other spaces where someone is participating as part of the DevToolkit community.
